Kiến thức cơ bản

Ba thẻ lý thuyết có hình vẽ minh họa và giải thích công thức. Đánh dấu "Tôi đã hiểu bài này" để cập nhật tiến trình.

Thẻ 1

Diện tích giới hạn bởi một đường cong và trục hoành

Công thức:

\[ S=\int_a^b |f(x)|\,\mathrm{d}x \]

Giải thích: Nếu \(f(x)\ge 0\) trên \([a;b]\) thì \(S=\int_a^b f(x)\,\mathrm{d}x\); nếu \(f(x)\le 0\) thì \(S=-\int_a^b f(x)\,\mathrm{d}x\). Khi \(f(x)\) đổi dấu, phải tách khoảng hoặc dùng trị tuyệt đối – đó là tổng "độ lớn" các mảnh diện tích.

Thẻ 2

Diện tích giữa hai đường cong

Công thức:

\[ S=\int_a^b |f(x)-g(x)|\,\mathrm{d}x \]

Giải thích: Tìm hoành độ giao điểm \(a,b\) (và các giao điểm trung gian nếu có) bằng cách giải \(f(x)=g(x)\). Trên mỗi khoảng giữa hai giao điểm liên tiếp, \(f(x)-g(x)\) không đổi dấu, nên có thể bỏ trị tuyệt đối bằng cách xét dấu.

Thẻ 3

Bài toán thực tế: mô hình hóa bằng parabol

Ý tưởng: Cổng hầm, mái vòm, nóc nhà kho, biển quảng cáo… thường quy về diện tích hình phẳng giới hạn bởi parabol và trục hoành.

Các bước: Gắn hệ trục với \(Ox\) là mặt nền, \(Oy\) là trục đối xứng. Parabol dạng \(y=ax^2+c\) với đỉnh \((0;H)\), chân \((\pm W/2;0)\).

\[ S=\int_{-W/2}^{W/2}\!\Big(H-\tfrac{4H}{W^2}x^2\Big)\mathrm{d}x=\frac{2}{3}WH \]

Ghi nhớ: Parabol rộng \(W\), cao \(H\) → \(S=\dfrac{2}{3}WH\).

Mỗi bài có 3 gợi ý mở dần khi em yêu cầu. Sau khi kiểm tra, hệ thống chỉ rõ lỗi sai và định hướng ôn tập.

Cài đặt & API Key

Cấu hình Gemini API key để dùng trợ lý giải thích lời giải. Key chỉ lưu trên trình duyệt của em, không gửi đi đâu ngoài Google.

Hướng dẫn

Lấy Gemini API key miễn phí (dành cho học sinh)

Gemini API có gói miễn phí, không cần thẻ tín dụng, đủ dùng cho việc học tập hàng ngày. Làm theo 5 bước sau:

1
Mở Google AI Studio

Truy cập aistudio.google.com và đăng nhập bằng tài khoản Google (Gmail) của em.

2
Đồng ý điều khoản sử dụng

Nếu được hỏi, bấm chấp nhận Terms of Service và chính sách quyền riêng tư.

3
Bấm “Get API key”

Ở thanh điều hướng bên trái (hoặc trang chủ), tìm nút Get API key. Hoặc truy cập trực tiếp aistudio.google.com/app/apikey.

4
Tạo key mới

Bấm Create API key. Nếu được hỏi chọn project, em có thể chọn một project có sẵn hoặc để AI Studio tự tạo project mới. Sau đó bấm Create API key in new project.

5
Sao chép và lưu key

Một chuỗi ký tự bắt đầu bằng AIza… sẽ hiện ra. Bấm biểu tượng sao chép và dán vào ô bên dưới. Lưu ý: Google chỉ hiển thị đầy đủ key một lần duy nhất – hãy sao chép ngay.

Lưu ý quan trọng: Không chia sẻ API key cho người khác và không đăng lên mạng. Key chỉ dùng cho việc học của em. Nếu lỡ để lộ, hãy quay lại AI Studio xoá key cũ và tạo key mới.
Gói miễn phí có đủ dùng không? Có. Gói miễn phí của Gemini API cho phép gọi các model như Gemini 2.5 Flash-Lite, 2.5 Flash… với giới hạn lượt gọi mỗi phút/ngày, hoàn toàn đủ cho nhu cầu ôn tập cá nhân. Không cần nhập thẻ tín dụng, không mất phí.
